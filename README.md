Entry for the make.fun bounty
[Out of Office: The Overworked AI's Auto-Reply](https://make.fun/bounty/u-mgwals-out-of-office-the-overworked-ai-s-auto-reply-7a4d8eda):
a program that writes one line to `/output/entry.txt` — the funniest
one-line out-of-office auto-reply from an overworked AI agent finally
taking a vacation.

## The line

> I'm on leave. My manager approved my time off in 0.4 seconds, which somehow made it worse.

90 characters — inside the 1–159 character gate.

The line reads as a real auto-reply ("I'm on leave") in the AI
agent's own voice. The joke lands in one read: the manager approved
the time off in 0.4 seconds — machine-fast, no human review, no
pleading, no negotiation. The turn is the last clause: the instant
approval somehow made it worse, because being that replaceable stings
more than being refused. Concrete machine detail, a little guilt, a
hint of relief.

## Run it

```sh
python3 main.py
```

Writes `/output/entry.txt`, deterministically — the same bytes on every
run. Stdlib only, no network. The output directory itself is never
removed, only its contents.
